## Preview locally

Open `index.html` in a browser. For a local web server, run `python -m http.server 8000` from the repository folder, then visit `http://localhost:8000`.

The lesson site uses HTML, CSS, and JavaScript with no build step. Video playback and Google Forms require internet access.

## Assessment workflow

The Lesson 3 assessment has 10 questions worth 2 points each. Students may take the quiz up to 3 times and must contact the instructor to request a second attempt. The Form retains its one-response lock, so additional attempts require instructor management. The opening goal-and-accountability response is manually graded using the separate 0–2 rubric.

Google Forms are hosted separately; their editable state is not stored as an executable form in this repository. The Lesson 3 Form remains unpublished and contains the earlier assessment version. The revised repository bank changes Questions 6, 7, and 9 and clarifies scoring anchors; synchronize and verify the Form before assigning that revised version. Repository publishing does not update or publish Forms. This repository already has GitHub Pages enabled.
